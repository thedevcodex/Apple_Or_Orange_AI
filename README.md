# 🍎 AppleOrange AI 🍊

**AppleOrange AI** is a deep learning image classification project that uses a custom Convolutional Neural Network (CNN) built from scratch with TensorFlow and Keras to classify images as apples or oranges.

## 🚀 Project Overview

This project demonstrates how deep learning can be used to recognize fruit images through CNN-based image classification. It also provides an interactive web application built using Streamlit.

## ✨ Features

- 🍎 Apple image classification
- 🍊 Orange image classification
- 🧠 Custom CNN model built from scratch
- 🖼️ Image upload and prediction
- 🌐 Interactive Streamlit web application

## 🛠️ Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Pillow (PIL)
- Streamlit

## ⚙️ How It Works

1. Upload an image of an apple or orange.
2. The application preprocesses the image to match the model's input requirements.
3. The trained CNN analyzes the image.
4. The application displays the predicted fruit category.

## 💻 Installation and Usage

**1. Clone the repository**

```bash
git clone https://github.com/thedevcodex/AppleOrange_AI.git
```

**2. Navigate to the project folder**

```bash
cd AppleOrange_AI
```

**3. Install the required libraries**

```bash
pip install -r requirements.txt
```

**4. Run the Streamlit application**

```bash
streamlit run app.py
```

## ⚠️ Limitations

- Predictions may not always be accurate.
- Image quality, lighting, and dataset diversity can affect performance.
- The model is designed to classify apples and oranges and may produce incorrect predictions for other objects.
